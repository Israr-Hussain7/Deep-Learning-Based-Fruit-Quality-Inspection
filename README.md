# Deep Learning-Based Fruit Quality Inspection Using Computer Vision

## Project Overview

This research project explores deep learning techniques for automated fruit quality inspection using computer vision. It focuses on classifying apples, bananas, and oranges into healthy and rotten categories.

Three CNN-based architectures are implemented and comparatively evaluated to investigate their classification performance.

## Models Implemented

- ResNet50
- MobileNetV2
- MobileNetV3Small

## Dataset

The dataset contains 2,949 usable images across six classes:

- Apple — Healthy / Rotten
- Banana — Healthy / Rotten
- Orange — Healthy / Rotten

The dataset is divided into training, validation, and testing sets.

## Model Performance

| Model | Test Accuracy |
|---|---:|
| ResNet50 | 99.33% |
| MobileNetV2 | 98.43% |
| MobileNetV3Small | 97.53% |

## Evaluation Metrics

- Accuracy

## How to Run

1. Open the Jupyter Notebook in Google Colab.
2. Upload or connect the required dataset.
3. Run the notebook cells in sequence.
4. Train and evaluate the models.
5. Upload an image to test fruit classification.

## Research Objective

To investigate and compare deep learning architectures for accurate and automated fruit quality inspection using computer vision.
